# smoke-coverage

AgentForge's smoke coverage: one agent, **hello-agent**, whose procedures exist to exercise what AgentForge does around a run — never what the model answers — through a caller, the client or the Temporal activity, the agent's image and a real model. It is generated by the plugin, and regenerates the hand-built `hello-agent` that covered this before A5.

## How it was generated

```bash
nx g @beruangai/agentforge:agentic-project smoke-coverage --directory packages/examples
nx g @beruangai/agentforge:agent --project smoke-coverage hello-agent --procedure Summarise
nx sync
```

What is maintained, scaffolded and detachable is listed in [AgentForge's README](../../../libs/agentforge/README.md#the-nx-plugin). The contract, the procedures and `options.ts` were written by hand into the scaffolds.

## What it covers

| Procedure | Exercises |
|---|---|
| `Summarise` | A typed output with a computed field; a session resumed by id |
| `SleepThenAnswer` | A run long enough to cancel, or to lose, mid-Bash |
| `KeepNote`, `RecallNote` | An S3 filesystem, `notebook`, scoped per topic: written in one container, read back in another |
| `Remember`, `Recall` | Auto memory in an S3 filesystem, `memories`, a space per request: saved in one container, recalled in another with no tools |

| Suite | Asserts |
|---|---|
| `e2e/local/hello-agent.test.ts` | A typed output, an attach under the same key, the run's record and its logged prompt; a resumed session; a cancel mid-Bash leaving the container idle |
| `e2e/local/temporal-activity.test.ts` | The Temporal activity returning the typed output while heartbeating, and cancelling its task when cancelled |
| `e2e/agentcore/hello-agent.test.ts` | On AgentCore: an attach to a completed task; a session resumed in another container from its transcript in S3; the notebook across containers; a memory across containers; a container stopped mid-Bash ending the task `LOST`, its retry running as attempt 2 |

## Running it

```bash
nx run @beruangai/smoke-coverage:e2e
```

```bash
nx run @beruangai/smoke-coverage:e2e-agentcore
```

`e2e` serves hello-agent locally through `serve-hello-agent`, with the subscription token from `.env.serve.local`, and runs the `local` project. `e2e-agentcore` deploys [smoke-coverage-infra](../smoke-coverage-infra/README.md) first and runs the `agentcore` project as the test role, resolving the agent from the deployment's runtime configuration.
