# golden-kata

AgentForge's example agentic project: a writer agent that writes a coding kata and a grader agent that grades one, sharing a base layer. It is generated by the plugin, and verified locally and on AgentCore before any consumer adopts a change.

## How it was generated

```bash
nx g @beruangai/agentforge:init
nx g @beruangai/agentforge:agentic-project golden-kata --directory packages/examples
nx g @beruangai/agentforge:agent --project golden-kata writer --procedure Write
nx g @beruangai/agentforge:agent --project golden-kata grader --procedure Grade
nx sync
```

Re-running any of them changes nothing; `nx sync:check` fails if a maintained file drifts from what the installed AgentForge generates. What is maintained, scaffolded and detachable is listed in [AgentForge's README](../../../libs/agentforge/README.md#the-nx-plugin).
